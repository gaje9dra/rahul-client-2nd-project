# BlushLine — Static Profile Directory

A responsive, pink-themed profile directory demo built using plain HTML, CSS, and JavaScript.

## Features
- 12 profile cards with placeholder descriptions and portrait imagery
- WhatsApp and phone-call action buttons
- Search by name and profile interests
- Interest filters
- Responsive navigation for mobile
- How-it-works, about, FAQ, and footer sections

## Run locally
Open `index.html` in a browser. No package installation or build step is required.

## Before publishing
This is a front-end mockup. Profile names, portraits, descriptions, availability indicators, and phone numbers are placeholders. Replace dummy WhatsApp/call links with verified contact details from consenting adults. Verify rights to photos and get consent to publish personal information. The page does not implement bookings, authentication, payment processing, or a backend.

The site loads fonts and portrait images from external providers, so those assets require an internet connection.
